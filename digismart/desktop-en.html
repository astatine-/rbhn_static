🔐 Password Security - Basics

Password Categories

Four levels of password security:

  • HIGHEST-RISK: Banking, Investments, Passport, Email, Key digital services → 16+ characters, unique
  • HIGH-RISK: Social media, quasi-social (mygate, adda), Job portals, Health care services → 12+ characters
  • MEDIUM-RISK: Utility services (zomato, amazon, makemytrip, etc), Uber, Coursera, .. → 12+ characters
  • LOW-RISK: Streaming, news → Simpler is okay

Common Patterns to Avoid

❌ NEVER Use:

  • password123, name+year, birthday (self, family), phone number
  • Same password everywhere
  • Sequential patterns

Use Password Manager - Bitwarden

✅ Bitwarden Benefits:

  • FREE, open-source
  • Generates unique passwords for each account
  • You remember ONE master password
  • Available at bitwarden.com
Install Bitwarden

🔑 2FA & Passkeys - Essential Protection

Two-Factor Authentication (2FA) - CRITICAL

✅ Why 2FA is Essential:

  • Enable on ALL financial accounts
  • Even if password stolen, 2FA protects you
  • Prevents 99% of account takeovers

Types: SMS OTP (good) | Authenticator app (better) | Hardware key (best)

Passkeys (The Future - NEW!)

🔑 What are Passkeys?

  • Uses fingerprint/face instead of password
  • Cannot be phished or stolen
  • Supported by Google, Apple, some banks
  • Check: Settings → Passkey/Passwordless

🎯 ACTION: : Enable 2FA on your HIGHEST and HIGH category services TODAY

Enable 2FA Now

📧 Phishing - Email Scams

Example: Fake Bank Email

From: noreply@hdfc-bank.co.in (fake!)

Subject: "Account will be closed"

Body: "Click here to verify within 24 hours..."

🚩 Red Flags:

  • Fake domain (real: hdfcbank.bank.in)
  • Generic greeting ("Dear Customer")
  • Urgent language
  • Asks you to click link

Protection

✅ How to Stay Safe:

  • NEVER click links in emails
  • Open banking app directly
  • Real banks use .bank.in domains
  • Call bank using number on YOUR card or your Relationship Manager

📱 Phishing - SMS Scams

Common SMS Scams

Account Lock: "Account locked. Verify now: [link]"

🚩 Sent from mobile number (banks use 6-char IDs)

Prize/Lottery: "Won ₹50,000. Claim here"

🚩 You didn't enter any lottery

Call forwarding: "Dial **21984xxx11# to allow delivery" →

🚩 Number starts or ends with * or #

Protection

✅ How to Stay Safe:

  • Banks don't send from regular 10 digit number (banks use XX-ICICIT-S or XX-AXISBK-T)
  • Never click links in SMS
  • NEVE dial numbers sent from unknown SMS
  • Real banks SMS from 6-character IDs ("HDFC", "ICICI")

🟢 Technical Attacks - WhatsApp Scams

Hacked Contact Scam

How it works:

Friend's WhatsApp hacked → "Emergency, send ₹10,000 urgently"

Protection: ALWAYS call person directly (phone call, not WhatsApp)

APK Files - EXTREMELY DANGEROUS

The Setup:

"Download app to register for lucky draw"

"Download app for cashback"

→ Install APK file

→ Spyware reads passwords, captures OTPs, steals contacts

Protection:

✅ How to Stay Safe:

  • NEVER click on APK files, even from friends
  • Only use Play Store/App Store
  • Android: Settings → Security → Unknown Sources → DISABLE

💻 Technical Attacks - Screen Sharing Scams

How It Works

The Process:

Could start via SMS, WhatsApp or even a phone call

1. "Install AnyDesk to process refund" or an app you are not familiar with

2. You install (legitimate app)

3. You give access code

4. They SEE and CONTROL your phone

5. Watch you enter passwords, transfer money

Real Example (Delhi 2024): ₹2,50,000 lost in minutes while watching helplessly

The Truth

Protection:

✅ How to Stay Safe:

  • Banks NEVER ask for screen sharing
  • E-commerce NEVER needs remote access
  • Delivery companies DON'T use these apps

Anyone asks for AnyDesk/TeamViewer = HANG UP

🔢 Social Engineering - OTP Trap - #1 Scam in India

How It Works

The Process:

1. "HDFC security. Suspicious activity detected"

2. "Someone tried to withdraw ₹50,000"

3. "Sending OTP. Read it to verify it's you"

4. OTP arrives (REAL, from your bank)

5. You share: "1-2-3-4-5-6"

6. Scammer uses it → Money GONE

The Absolute Truth

Protection:

✅ How to Stay Safe:

Banks will NEVER ask for OTP. Not on phone, not via email, NEVER EVER.

Safe to Share OTPs:

✓ Food delivery

✓ Package delivery

❌ NEVER financial OTPs

💸 Social Engineering - UPI Mistake Scam

How It Works

The Process:

1. Notification: "Received ₹5,000"

2. WhatsApp: "Sorry, wrong number. Return urgently"

3. You feel obligated, send ₹5,000 back

4. Hours later: Original ₹5,000 FAILS (was from stolen account)

5. Your return was REAL → You lost ₹5,000

Protection

Protection:

✅ How to Stay Safe:

  • NEVER return unexpected money immediately
  • Wait 24-48 hours for settlement
  • Check actual bank balance (not just notification)
  • Let bank handle reversal through official process

🎯 QR Code Safety: Generate YOUR OWN QR to receive | Never scan buyer's QR

🚨 Social Engineering - Digital Arrest

The Setup

Initial Contact:

"CBI. You're involved in money laundering. Arrest warrant issued."

“Customs: A package sent by you has drugs”

“Police: Your son has been arrested”

The Stages:

1. Call creating fear: "Arrest in 24 hours"

2. Video call: Fake police uniform, fake documents

3. App download: "Digital Arrest Portal" = spyware

4. Money extraction: "Transfer to govt account" ₹2-5 lakhs

The Truth

🛑 REALITY:

  • ❌ Police DON'T arrest via phone/video
  • ❌ No "digital arrest" provision exists
  • ❌ Government DOESN'T ask for money
  • ✓ Real police come with warrant

If you get such call: Hang up → Go to police station → File complaint

🛡️ 3 Rules = 90% Protection

RULE 1: DON'T CLICK LINKS

❌ Bank emails, tax refunds, account updates

✓ Type URL yourself or use banking app

Why: 80% of scams start with clicked link

RULE 2: DON'T ACT ON MESSAGES

❌ Friend asking for money, account locked alerts

✓ Call person/company directly, use official app

✓ Exception: Transaction alerts OK to read (don't click)

RULE 3: DON'T INSTALL UNKNOWN APPS

❌ APK files from WhatsApp, apps from websites

✓ Only: Play Store (Android) or App Store (iPhone)

✓ Android: Disable "Unknown Sources" in Settings

🔒 Four Advanced Steps

Separate Bank Accounts

Strategy:

Main - minimal digital activity | Secondary (~₹20K-50K) - UPI/shopping

Benefit: If compromised, only ₹20K-50K at risk

Set Transaction Limits

Settings:

UPI limit: ₹5-10K (not ₹1L) | Card: ₹10-50K

How: Banking app → Settings → Limits

Family Secret Phrase

Setup:

Agree on codeword (e.g., "Rainbow42")

Rule: Any money request MUST include codeword

Defeats: Hacked WhatsApp, SMS spoofing, AI voice cloning

You don't call me, I will call you

Slightest suspicion, hang up

Call back from address book
